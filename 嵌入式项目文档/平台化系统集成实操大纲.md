# 手表项目系统集成课程路线（展示版）

## 第一阶段：从资源分配表到系统最小骨架

**01\_资源分配表与系统边界**
&#x20;先把主控、屏幕、触摸、传感器、存储、BLE、电源等资源边界讲清楚，建立系统级开发视角。

**02\_CubeMX最小工程建立**
&#x20;根据资源分配表，把时钟、GPIO、UART、SPI、I2C、ADC、TIM、DMA 等基础外设先配置成一个可运行底座。

**03\_系统第一刀分层设计**
&#x20;不是先写驱动，而是先把工程骨架切出来，明确 App / Service / Platform / Impl / Vendor 的职责边界。

***

## 第二阶段：对象模型、数据模型与生命周期

**04\_对象模型设计**
&#x20;建立 object / device / service 的基础模型，让系统里的“对象”先有清晰定义。

**05\_数据模型设计**
&#x20;梳理 cfg / ctx / data / ops 四元组，让配置、状态、数据、行为各归其位。

**06\_管理模型与生命周期设计**
&#x20;设计 register / init / start / process / stop / deinit 主线，让系统具备可管理的启动与运行机制。

***

## 第三阶段：公共基础层与 MCU 抽象层搭建

**07\_公共基础规则建立**
&#x20;建立类型系统、错误码、断言、版本与配置系统，为后续所有模块统一底层规则。

**08\_日志与诊断系统接入**
&#x20;接入 RTT / EasyLogger，补上版本信息、启动信息、断言出口和基础诊断能力。

**09\_MCU基础能力抽象**
&#x20;先抽 irq / tick / gpio / uart，再逐步扩到 dma / timer / adc / watchdog / spi / i2c / flash。

***

## 第四阶段：板级资源平台化与器件接入

**10\_板级资源建模**
&#x20;把 pinmap、busmap、powermap、irqmap 建起来，把资源表从文档变成代码资产。

**11\_board初始化与板级语义接口**
&#x20;不再直接翻 GPIO，而是沉淀出 board\_backlight\_on、board\_display\_reset、board\_motor\_enable 这类板级语义接口。

**12\_核心器件平台化接入**
&#x20;完成 display、touch、imu、temp\_humi、battery、storage 等核心器件的统一访问入口。

***

## 第五阶段：RTOS 与中间件运行时系统

**13\_FreeRTOS接入与 OS 抽象层建立**
&#x20;引入 RTOS，但不让业务层直接绑死 FreeRTOS API，而是通过 OSAL 统一任务、延时、临界区等能力。

**14\_OSAL能力补全**
&#x20;继续补 mutex、sem、queue、event、timer，让任务间通信和同步进入可复用状态。

**15\_中间件接入规范**
&#x20;把日志、GUI、存储、加密等中间件接入方式标准化，明确第三方源码区和适配层必须分离。

***

## 第六阶段：Service 层系统能力搭建

**16\_系统基础服务搭建**
&#x20;建立 log、diagnosis、watchdog、power 等系统服务，把底层能力收敛成服务能力。

**17\_设备服务搭建**
&#x20;建立 battery、sensor、backlight、storage 等设备服务，让业务层不再直接碰底层驱动。

**18\_手表业务服务搭建**
&#x20;逐步形成 time、ble、ota、event bus 等业务服务骨架，让平台具备完整系统协作能力。

***

## 第七阶段：App 层系统集成

**19\_App启动链路与系统状态机**
&#x20;建立 boot、init、ready、running、low\_power、recovery 的主状态流，让系统从“能跑”变成“会组织”。

**20\_UI与业务装配**
&#x20;把时间、电量、背光、传感器、BLE 状态统一挂到页面，跑通 Service → App → UI 的闭环。

**21\_低功耗、唤醒与异常恢复**
&#x20;完善低功耗进入、唤醒恢复、reset reason 处理和异常重启恢复路径，形成产品级运行闭环。

***

## 第八阶段：工程化闭环与量产演进

**22\_调试钩子、自检与 FCT 预留**
&#x20;给平台补上可测性，预留调试入口、自检能力和产测接口。

**23\_构建体系、版本与发布管理**
&#x20;把 clean、build、version、Debug / Release / Factory 等构建流程规范化。

**24\_量产接口、OTA闭环与平台复盘**
