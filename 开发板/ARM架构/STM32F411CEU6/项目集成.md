# 📖 嵌入式项目集成：系列笔记索引

> 项目集成是将独立开发的软硬件模块——MCU 启动代码、外设驱动、RTOS、中间件、应用逻辑——按分层架构组合为完整嵌入式系统的工程过程。

本系列以 **通用方法论为主线**，以 GR5526 SDK 的 `graphics_lvgl_831_gpu_demo_360p` 工程为贯穿案例，通过 **Adapter 适配层** 串联各层关系。

---

## 系列笔记目录

| # | 笔记 | 内容 | 阅读时间 |
|---|------|------|---------|
| 01 | [[01_嵌入式项目集成：概念与架构总览]] | 五层模型、依赖规则、配置中心、控制反转 | 15 min |
| 02 | [[02_嵌入式项目集成：OS层与OSAL设计]] | OSAL 编译期多态、最小 API、裸机实现 | 12 min |
| 03 | [[03_嵌入式项目集成：BSP层与三段式Adapter]] | Wrapper→Porting→Driver 解耦模式 | 15 min |
| 04 | [[04_嵌入式项目集成：APP层与启动流程]] | 内部子层、启动链、生产者-消费者任务 | 15 min |

### 阅读路径

```
01_概念与架构总览  ← 从这里开始，建立整体认知
    ├── 02_OS层与OSAL设计      ← APP通过OSAL调RTOS
    ├── 03_BSP层与三段式Adapter ← APP通过drv_adapter调硬件
    └── 04_APP层与启动流程      ← 汇总：main()编排所有层
```

### Adapter 串联视角

```
                    ┌──────────────┐
                    │  04_APP层    │  main() < 50行 / Manager / Task / Logic
                    └──┬───────┬──┘
                       │       │
          osal_*() API │       │ drv_adapter_*() API
                       │       │
          ┌────────────▼──┐ ┌──▼─────────────┐
          │  02_OS层       │ │  03_BSP层       │
          │  OSAL Wrapper  │ │  三段式Adapter  │
          │  ↓ os_impl_*.c │ │  W→P→D解耦     │
          │  FreeRTOS/裸机  │ │  LCD/Flash/触摸 │
          └────────────────┘ └────────────────┘
```
