## 1. 架构原理 (Architecture)

### 必学内容

```
├── 寄存器组织
│   ├── 通用寄存器 (R0-R15)
│   ├── 状态寄存器 (SR/PSW/CPSR)
│   ├── 程序计数器 (PC)
│   └── 堆栈指针 (SP)
│
├── 指令集
│   ├── 数据传输指令 (MOV, LDR, STR)
│   ├── 算术指令 (ADD, SUB, MUL)
│   ├── 逻辑指令 (AND, OR, XOR)
│   ├── 移位指令 (LSL, LSR, ASR)
│   └── 控制指令 (B, BL, RET)
│
├── 寻址模式
│   ├── 立即数寻址
│   ├── 寄存器寻址
│   ├── 直接寻址
│   ├── 间接寻址
│   └── 基址变址寻址
│
└── 流水线结构
    ├── 取指 (Fetch)
    ├── 译码 (Decode)
    └── 执行 (Execute)
```

### 学习方法

```c
// 1. 阅读官方手册的 "Architecture" 章节
// 2. 手写汇编代码理解指令
// 3. 使用反汇编工具查看编译结果

// 示例: STM32 Cortex-M4 寄存器操作
volatile uint32_t *const GPIOA_MODER = (uint32_t *)0x40020000;

// 配置 PA5 为输出模式
*GPIOA_MODER &= ~(0x3 << 10);  // 清除位 [11:10]
*GPIOA_MODER |= (0x1 << 10);   // 设置位 [11:10] = 01 (输出)
```

## 2. 外设驱动 (Peripherals)

### 常用外设优先级

```
├── 必学 (第1周)
│   ├── GPIO (输入/输出/中断)
│   ├── UART (串口通信)
│   ├── Timer (定时器)
│   └── Watchdog (看门狗)
│
├── 重要 (第2-3周)
│   ├── I2C (传感器通信)
│   ├── SPI (高速通信)
│   ├── ADC (模数转换)
│   └── PWM (脉宽调制)
│
└── 进阶 (第4周+)
    ├── DMA (直接内存访问)
    ├── CAN (工业总线)
    ├── USB (设备/主机)
    └── Ethernet (网络)
```

### 统一驱动模板

```c
typedef struct {
    void (*init)(void);
    void (*write)(uint8_t *data, uint16_t len);
    void (*read)(uint8_t *buffer, uint16_t len);
    void (*deinit)(void);
} Peripheral_Driver;

// GPIO 驱动示例
void gpio_init(GPIO_TypeDef *GPIOx, uint32_t pin, uint32_t mode) {
    // 1. 使能时钟
    RCC->AHB1ENR |= (1 << GPIOx-clock_index);
    
    // 2. 配置模式
    GPIOx->MODER &= ~(0x3 << (pin * 2));
    GPIOx->MODER |= (mode << (pin * 2));
}
```

## 3. 存储体系 (Memory)

### 存储映射

```
├── Flash (程序存储)
│   ├── 起始地址 (0x08000000 for STM32)
│   ├── 容量 (64KB, 128KB, 512KB...)
│   └── 擦写特性 (页擦除/块擦除)
│
├── RAM (数据存储)
│   ├── SRAM (静态 RAM)
│   ├── 位带操作 (Bit-banding)
│   └── DMA 缓冲区
│
├── 特殊存储区
│   ├── 外部存储接口 (FSMC/FMC)
│   ├── Quad-SPI (QSPI)
│   └── SDRAM
│
└── 存储保护
    ├── MPU (内存保护单元)
    └── 访问权限控制
```

### 内存映射示例

```c
// STM32F4 内存映射
#define FLASH_BASE      0x08000000  // Flash 起始
#define SRAM_BASE       0x20000000  // SRAM 起始
#define PERIPH_BASE     0x40000000  // 外设起始

// GPIOA 基地址 = PERIPH_BASE + 0x00020000
#define GPIOA           ((GPIO_TypeDef *)0x40020000)
```

```
├── 中断控制器
│   ├── NVIC (Cortex-M)
│   ├── AIC (AVR)
│   └── INTC (PIC)
│
├── 中断优先级
│   ├── 抢占优先级 (Preemption)
│   ├── 子优先级 (Sub-priority)
│   └── 优先级分组
│
├── 中断向量表
│   ├── 复位向量
│   ├── 异常向量
│   └── 外设中断向量
│
└── 中断处理
    ├── 中断服务函数 (ISR)
    ├── 中断嵌套
    └── 中断屏蔽
```

### 中断配置模板

```c
// UART 中断服务函数
void UART2_IRQHandler(void) {
    if (USART2->SR & USART_SR_RXNE) {
        // 接收中断处理
        uint8_t data = USART2->DR;
        // 处理数据...
    }
    
    if (USART2->SR & USART_SR_TXE) {
        // 发送中断处理
        // 发送下一字节...
    }
}

// 中断优先级配置
NVIC_SetPriority(USART2_IRQn, 1);  // 设置优先级
NVIC_EnableIRQ(USART2_IRQn);       // 使能中断
```

### HardFault 处理

```c
void HardFault_Handler(void) {
    // 读取故障状态寄存器
    volatile uint32_t cfsr = SCB->CFSR;
    volatile uint32_t hfsr = SCB->HFSR;
    volatile uint32_t mmfar = SCB->MMFAR;
    volatile uint32_t bfar = SCB->BFAR;
    
    // 死循环，方便调试器捕获
    while (1);
}
```

### printf 重定向

```c
int fputc(int ch, FILE *f) {
    USART_SendData(USART1, (uint8_t)ch);
    while (USART_GetFlagStatus(USART1, USART_FLAG_TXE) == RESET);
    return ch;
}
```

## MSP vs DSP 对比

### 基本定义

| 特性 | MSP (MSP430) | DSP (TMS320C2000等) |
|------|-------------|---------------------|
| **全称** | Mixed Signal Processor | Digital Signal Processor |
| **厂商** | Texas Instruments (TI) | TI、ADI、NXP等 |
| **定位** | 超低功耗微控制器 | 高速数字信号处理 |

### 核心区别

```
┌─────────────────────────────────────────────────────────────────┐
│                        MSP430 vs DSP                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  MSP430 (混合信号处理器)                                         │
│  ├── 架构: 16位 RISC                                             │
│  ├── 功耗: 极低 (待机 <1μA)                                      │
│  ├── 时钟: 1-25 MHz                                              │
│  ├── 应用: 电池供电设备、传感器、仪表                              │
│  └── 特点: 简单指令集、低功耗模式丰富                              │
│                                                                  │
│  DSP (数字信号处理器)                                            │
│  ├── 架构: 24/32位 专用信号处理                                   │
│  ├── 功耗: 较高 (需要高速运算)                                    │
│  ├── 时钟: 100-400 MHz                                           │
│  ├── 应用: 音频处理、电机控制、通信系统                            │
│  └── 特点: 硬件乘法器、流水线、哈佛架构                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 架构对比

| 架构特性 | MSP430 | DSP |
|----------|--------|-----|
| **总线架构** | 冯·诺依曼 | 哈佛 (分离程序/数据总线) |
| **乘法指令** | 软件模拟 (4周期) | 硬件单周期 |
| **寻址模式** | 基础 (6种) | 丰富 (支持循环寻址) |
| **累加器** | 16位 | 32/40/56位 |
| **存储器** | 小容量 (几KB~几百KB) | 大容量 (几MB) |
| **中断响应** | 较慢 | 快速 (专用中断硬件) |

### 典型型号

**MSP430 系列:**
```
MSP430F2013     → 2KB RAM, 16KB Flash, 20MHz
MSP430G2553     → 512B RAM, 16KB Flash, 16MHz  
MSP430FR5739    → 1KB RAM, 16KB FRAM, 24MHz
```

**DSP 系列:**
```
TMS320F28379D   → 200KB RAM, 1MB Flash, 200MHz
TMS320C6748     → 448KB RAM, 4MB Flash, 456MHz
ADSP-21489      → 5Mbit RAM, 400MHz
```

### 应用场景对比

```
MSP430 适用场景:
├── 智能电表 (电池供电，10年寿命)
├── 温度传感器 (超低功耗采集)
├── 便携式医疗设备 (血糖仪、血压计)
├── 工业传感器 (4-20mA 环路供电)
└── 无线传感器节点 (ZigBee/LoRa)

DSP 适用场景:
├── 音频编解码器 (MP3/AAC 解码)
├── 电机控制 (FOC 矢量控制)
├── 雷达信号处理 (FFT/滤波)
├── 图像处理 (边缘检测/压缩)
└── 通信基站 (调制解调)
```

### 选型建议

| 需求 | 选择 | 理由 |
|------|------|------|
| **电池供电 >1年** | MSP430 | 超低功耗是核心优势 |
| **需要 FFT/滤波** | DSP | 硬件加速信号处理 |
| **简单控制逻辑** | MSP430 | 成本低、功耗低 |
| **实时电机控制** | DSP | 快速响应、高精度PWM |
| **传感器采集** | MSP430 | 内置ADC、低功耗 |
| **音频处理** | DSP | 专用音频外设、高算力 |
