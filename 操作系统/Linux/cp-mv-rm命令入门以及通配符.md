cp命令（copy）用于复制文件/文件夹

```
cp [-r] 参数1 参数2
```

-r选项用于复制文件夹使用

参数1是被复制文件的Linux路径地址

参数2是存放复制文件的Linux路径地址

<br/>

mv命令（move）用于移动文件/文件夹

```
mv 参数1 参数2
```

参数1是被移动文件/文件夹的Linux路径地址

参数2是需要移动到的Linux路径地址，目标不存在会对被移动文件/文件夹进行改名,确保目标存在

<br/>

rm命令（remove）用于删除文件/文件夹

```
rm [-r -f] 参数1 参数2 …… 参数N
```

-r表示用于删除文件夹

-f表示force，强制删除

参数表示需要删除的文件/文件夹的Linux路径

<br/>

通配符*，用于做模糊匹配，匹配任意内容

test*，表示匹配任何以test开头的内容

*test，表示匹配任何以test结尾的内容

*test*，表示匹配任何包含test的内容
